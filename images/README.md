# images/

題材の背景に使う模式図を置く場所。JSON の `baseImageUrl` に `images/ファイル名` を書くと表示される。

- 使った図の出典・ライセンスを、下の表と `index.html` の「出典」に必ず書く。
- Servier Medical Art は CC BY 4.0（出典の表示が必要）。クレジットの書式は https://smart.servier.com/ の案内に従う。
- 暗い背景で見やすいよう、線を明るい色にした SVG/PNG を推奨。

| ファイル | 出どころ | ライセンス | 使っている題材 |
|---|---|---|---|
| （例）shoulder.svg | Servier Medical Art | CC BY 4.0 | rotator-cuff |
